# SkyCast - Weather Forecast & Analytics

SkyCast is a modern, responsive web application for multi-model meteorology and forecast analytics powered by the Open-Meteo API.

## Features

1. **Weather Report**: Real-time current weather metrics, WMO code descriptions, wind speed, humidity, and min/max temperature ranges with seamless Celsius (°C) and Fahrenheit (°F) conversion.
2. **Interactive Tools**: Temperature unit toggle, preset location switcher, custom coordinate inputs, and interactive daily forecast selectors.
3. **Hourly / Real-Time Forecast**: 24-hour temperature curve rendered with Chart.js, featuring interactive tooltips displaying hourly temperature, wind speed, and humidity metrics.
4. **Geographic Forecast Access**:
   - Live city search with auto-complete powered by Open-Meteo Geocoding API.
   - **Browse by Country**: Interactive 3-level accordion (Country -> Province/Region -> City) with custom-styled scrollbars, live search filtering, pagination for >100 cities, item counters, and location summary cards.
5. **Model-Based Weather Prediction**: Compare meteorological forecasts generated by different global weather simulation models (GFS, ECMWF, ICON).

## Running the Application

Because the application fetches data from `data/world.json` and external APIs using standard web `fetch()`, it **must be run from a local HTTP server** (running via `file://` directly in the browser will block requests due to CORS/Fetch security rules).

To start a local development server on port 3000:

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000` in your web browser.
